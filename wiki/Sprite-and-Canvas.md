# Sprite and canvas

The **Sprite** menu changes the whole sprite.

| Command | Does |
| --- | --- |
| **Properties** | Renames the sprite (the name is used for saved and exported files) and shows its size, frame, layer and colour counts. |
| **Canvas size** | Grows or crops the canvas to a new width and height (up to 4096), around an anchor: top left, top, centre, bottom (feet stay put) or bottom left. |
| **Trim canvas to content** | Crops to the drawn pixels on every frame and layer. |
| **Scale** | Scales the whole sprite 2×, 3× or 4× by nearest neighbour. For free scaling or rotation use [RotSprite](Selections-and-Editing#rotate-and-scale-rotsprite). |
| **RGB colour** / **Indexed colour** | Switches the colour mode. See [Colour and palettes](Colour-and-Palettes#rgb-and-indexed). |
| **Keep blends on the palette** | In indexed mode, puts blended layer results back on the nearest palette colour. |

## Zoom and view

| Command | Key |
| --- | --- |
| Zoom in / out | `+` / `-`, or scroll |
| Fit the sprite to the window | `0` |
| Pan | Space-drag, middle-drag, or two fingers |

Zoom runs from 100% to 6400%.
